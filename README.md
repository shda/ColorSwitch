# ColorSwitch

**Color Switch** – это популярная мобильная аркада с простым, но увлекательным геймплеем, основанным на реакции и точности.  

### **Суть игры:**  
- Вы управляете шариком, который автоматически движется вверх (или в другую сторону, в зависимости от режима).  
- На пути встречаются различные цветные препятствия. Чтобы пройти через них, цвет вашего шарика должен совпадать с цветом преграды.  
- Цвет шарика меняется при прохождении через специальные круги-переключатели.  

### **Особенности:**  
🔹 **Разные режимы**: классический, обратный, выживание, змейка и другие.  
🔹 **Яркий дизайн**: красочная графика и эффекты.  
🔸 **Сложность**: игра кажется простой, но требует отличной реакции и timing.  
🔺 **Кастомизация**: можно разблокировать новые скины для шарика.  

### **Почему это популярно?**  
🎮 **Простота + вызов**: легко начать, но сложно мастерски пройти уровни.  
⏳ **Динамика**: короткие сессии идеальны для мобильной игры.  
🌍 **Мультиплеер**: в некоторых режимах можно соревноваться с друзьями.  

Идеально для тех, кто любит головоломки на реакцию! 🚀
